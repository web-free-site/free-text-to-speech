Free Text to Speech is maintained as part of the web-free.site project hub.

For bugs in the upstream web demo, see piper-tts-web-demo issues. For voice licensing questions, consult Piper's licensing guide and each voice MODEL_CARD on Hugging Face.

Hosting and site issues: open an issue in the web-free-site/free-text-to-speech repository on GitHub if you have access, or use the contact options listed on web-free.site.
