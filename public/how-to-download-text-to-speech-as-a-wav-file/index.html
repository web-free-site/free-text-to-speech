How to download text to speech as a WAV file

After you generate audio on the home page, the tool merges chunks into one waveform and encodes a 16-bit PCM WAV file you can save like any other download.

  1. Enter your script and pick a voice on the home page.
  2. Click Generate and wait until playback is ready.
  3. Press Download WAV. Your browser saves audio.wav (rename after saving if you like).

WAV is uncompressed and works in video editors, presentation software, and accessibility workflows without extra conversion.

FAQ

Can I use the file commercially?
Check each voice's dataset license on our About page and Piper's commercial-use list.
Does download work on mobile?
Yes on current mobile browsers; use a shorter test phrase if storage or memory is limited.
